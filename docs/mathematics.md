# 顶点移动、离散 IF 与 Prony：数学分析

本文件是探索性技术分析，不是投稿稿件。源码依据是 2026-11-03 获取的 GTEMPO、QuAPI 及配套包；准确提交见 `results/source_versions.txt`。数值结论和适用范围见根目录报告。以下“精确”必须说明所针对的对象。

## 1. 首先区分三个不同对象

连续时间非相互作用费米浴被积掉后，影响泛函为

$$I[ā,a]=\exp\left[\int_C dz\int_C dz'\,ā(z)\,Δ(z,z')\,a(z')\right].$$

对于线性杂化，连续核满足 $Δ=Vg_BV†$。浴是高斯的，因此这个连续时间二次型本身是精确的；不存在被遗漏的高阶浴累积量。

选定离散场及其插值后，可写 $a(z)=\sum_j φ_j(z)a_j$，以及独立的共轭场插值 $ā(z)=\sum_i \bar φ_i(z)ā_i$。一致的离散核是

$$K_{ij}=\int_C dz\int_C dz'\,\bar φ_i(z)\,Δ(z,z')\,φ_j(z').$$

把这个离散核用于某个系统传播子，还需要匹配相干态插入位置、Berezin 测度、轮廓闭合、初态及观测量。核积分准确不等于最终传播格式已经高阶。

另一个对象是先指定离散传播链，再精确积掉浴，例如每步取 $B=\exp[-ih(H_B+H_{SB})]$，在步之间插入系统传播子。这种“对离散链精确”的 IF 与分片冻结源的连续核投影通常不同。其 Schur 补含有更高次的耦合依赖，是单步内的多次交换及变量定义所致，不能解释成连续高斯浴具有高阶累积量。

## 2. 顶点移动不是一个无条件合法的精度修正

如果只是改变 Grassmann 变量的标记，则系统作用量、IF、观测量、初态及积分测度都要一起变换，积分结果保持不变。只改变 IF 的矩阵条目而保留其他部分，是改变离散格式。

在分支内部，将一个端点平移一步的效应可形式地写成

$$K(t_i,t_{j+1})=K(t_i,t_j)+h\,∂_{t_j}K(t_i,t_j)+O(h^2).$$

离散核条目本身还含积分权重；上式只描述平移对光滑核的相对影响。它可以改变最终误差中的一阶系数，甚至偶然抵消某个模型和观测量的一阶项，但不自动保证二阶。

真实轮廓还有时间排序跳跃、分支起止和转折点。不能在这些位置使用光滑平移公式代替独立推导。QuAPI 实时装配实际不仅移动列，还去掉若干边界行列，并把原来的等时和放到动能连接的最近邻位置。它是一整套离散端点约定，不是简单的采样平移。

因此，顶点移动的合理性必须相对于具体传播链判断。它不需要在视觉上“自然”，但需要在相干态单步矩阵元中有明确来源；仅凭某个最终观测量变准确不足以证明普适正确。

## 3. 为什么 Prony 在数学上并不排斥移动

设平滑尾部有指数展开

$$f_d=\sum_{ℓ=1}^{r}c_ℓ λ_ℓ^d.$$

则前移仍是 $f_{d+1}=\sum_ℓ(c_ℓλ_ℓ)λ_ℓ^d$，极点完全不变。后移同样只改变系数，但直接除以小极点会不稳定；对零极点应改用延迟状态，而不是除法。

问题出在移动后，光滑尾部和局部项不再是同一条序列。以正向同支块为例，源码所需的下三角滞后为

$$k_1=E,\qquad k_d=f_{d-1}\quad(d≥2).$$

这里 $E$ 是原来的两个同胞时序三角积分之和。一般并不等于平滑尾部的外推。因此，不能让普通平滑指数拟合负责“接触项加移动尾部”的全部内容。

当前 GTEMPO 的 `_vertex_shifted_parts` 直接把尾部交给以一为起点的指数拟合，又禁用了最近邻修正。它不是对目标序列的精确表示。即使减小拟合容差，也不会自动修复缺失的局部项或尾部下标。此外，源码注释所述两个算符通道的上下三角方向与本次逐系数提取不一致：移动构造需要沿用未移动生成器的算符方向，将相应的上、下尾部分别放回正确通道。该问题是装配实现问题，不能归因于 Prony 理论。

## 4. 稳定、简单的表示：局部项加延迟指数尾部

推荐直接表示

$$k_d=E\,δ_{d,1}+\mathbf{1}_{d≥2}\sum_{ℓ=1}^{r}w_ℓλ_ℓ^{d-2}.$$

只对 $d≥2$ 的尾部做 Prony，最近邻系数 $E$ 精确保留。这里不需要制造极小极点，也不需要用大系数抵消。

一个有限状态 MPO 就能表示它。虚状态由起始、一个延迟状态、各个指数通道和结束组成。允许的跃迁是：起始到延迟放入左端算符；延迟到结束放入最近邻右端算符并乘 $E$；延迟到指数通道乘 $w_ℓ$；通道自循环乘 $λ_ℓ$；通道到结束放入右端算符。中间位置按费米约定带 Jordan–Wigner 串。若尾部有 $r$ 个极点，这个核生成器只需 $r+3$ 个虚状态，含精确零极点也没有除零问题。

这给出“移动与 Prony 相容”的构造性证明。它只证明核生成器的表示；把它接入当前 `ExactTTIIF` 的专用三状态指数公式，还需要扩展指数化接口，不能声称现有接口原样支持这个更大状态单元。

另一条接入路径是先用已有尾部算法，再乘精确局部因子。Grassmann 二次单项式属于偶元，相互可交换；对不同腿的单项式 $X=ā_i a_j$ 有 $X^2=0$，故

$$\exp(δK_{ij}X)=1+δK_{ij}X.$$

因而 IF 可以严格分解为平滑尾部、短程修正和边界修正的乘积；因这种分解本身引入的 Baker–Campbell–Hausdorff 误差为零。实际 MPS 压缩仍有截断误差。

边界开窗一般破坏有限矩阵的整体 Toeplitz 形式，但内部仍平移不变。可保留同一体单元，在边界改变张量或乘有限个行列因子。不能要求具有有限起止的 Keldysh 轮廓在每个位置都使用完全相同张量。

## 5. 混合轴不能逐块照搬实时位移

混合轮廓的虚时段编码相关热初态，交叉块编码实虚关联。其闭合边、反周期符号及结合处传播子与分离初态 Keldysh 轮廓不同。若只移动 IF 中的一组分支索引，可能同时改变了初态和观测量插入的相对位置。

因此目前混合位移出现不收敛偏差，说明该装配与当前 GTEMPO 管线不匹配；它不能证明所有经一致推导的混合离散格式都会变差。也不能从实时收益推断混合轴应该做同样操作。实虚交叉块本来就不是单一实时间滞后的 Toeplitz 核，宜用分块可分离展开及结合处专用张量。

## 6. 更换离散格式时应采用单步推导

若希望彻底去掉事后位移约定，可从相干态单步传播子开始。将浴能量和杂化放入联合二次型单步矩阵 $W=\exp(-ihh_Q)$，再精确做高斯消元：

$$K_{\mathrm{eff}}=M_{II}-M_{IB}M_{BB}^{-1}M_{BI},\qquad P\propto\det M_{BB}.$$

其中 $P$ 是必须保留的整体因子，不能仅因归一化观测量中常常约去而忽略。该方法的端点来自传播子连接关系，因而没有“是否人为移动”的额外自由度。QuAPI 已提供 `exact_fermionic_Δt` 等参照接口，可以用来校准更便宜的格式。

“相对于骨架的纯浴核”不能直接与任意杂质传播子相乘而自动给出精确分裂链。例如单模块中，先作用 $A=\mathrm{diag}(x,1_B)$、再作用 $B=W$ 时，联合矩阵为 $WA$；杂化块 $W_{BI}$ 和杂质块都要带入射腿相位 $x$。若只把 $x$ 放进自由杂质动能，而 IF 仍来自 $W$ 减单位骨架，会漏掉这些因子。本次非零杂质能量失败控制直接显示了该差异。

对称单步为 $A^{1/2}WA^{1/2}$。对应消元后的核，在正支到达的共轭腿和离开的湮灭腿各乘半步相位，负支乘相应共轭因子。本次普通单能级实现由此与独立对称链吻合；对相互作用杂质不能把这些多体局部传播子简化为标量相位。

这种 Schur 构造不意味着最终核一定适合一个简单的标量 Prony 展开：浴块在单步内经过杂质产生有效混合，有限温度初态与该浴块一般不对易，轮廓端点也会留下修正。连续谱下显式模式消元成本可观。因此它是更清楚的数学参照，不是未经验证就更便宜的长时算法。

一般系统可采用对称分裂：杂质半步、精确二次型整步、杂质半步。固定总时长下，适当有界条件和一致的初态、观测量插入可得到全局二阶。原始非对称链的误差阶不能仅由单步浴核是否精确来认定；某些对角格林函数还可能出现额外消去。

## 7. 改动最少的精度替代：先外推观测量

若当前不移动格式在固定物理时间有稳定展开 $O_h=O+c_1h+c_2h^2+\cdots$，则

$$O_{\mathrm{R}}(h)=2O_{h/2}-O_h=O+O(h^2).$$

应先分别完成两次归一化观测量计算，再对齐同一物理时间外推；不能外推误差范数，也不能随意平均两个 IF。混合轴须同步缩小实、虚步长，或分别拟合两个步长的误差。该法不改变 Prony 核表示，但至少要增加一套更细网格计算。它不能消除压缩、拟合、浴离散等误差，也不适用于未收敛的错误位移管线。

## 8. 代码定位

- QuAPI `src/contourindex.jl`：普通及 BCS 的轮廓索引访问器、实时开窗和同支移动、虚时与混合回退。
- QuAPI `src/dense/fermion.jl`：稠密装配的对应约定。
- QuAPI `src/exactfermionic.jl`：指定离散链的单步矩阵和 Schur 补参照。
- GTEMPO `src/influencefunctional/ttiif/util.jl`：移动尾部和被禁用的等时修正。
- GTEMPO `src/mpo/mpohamiltonian/schurmpo/exponentialdecay.jl`：末端算符附带极点的旧参数化。
- ExpExp `src/expansion.jl`：指数序列以一步为起点的拟合约定。
- GTEMPO `performance/firstorder/vertex_shift_accuracy.jl`：上游旧基准及其适用范围；本次独立计算不直接引用其旧结果作为新实测。
