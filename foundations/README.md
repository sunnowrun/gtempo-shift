# 已引用的理论基础快照

这九个文件来自项目实际读取的一阶理论目录及相关 Weyl/contact fork，内容逐字保存；原路径、快照名称和 SHA-256 见 [sources.json](sources.json)。其中两个 Python 工具与最终研究目录的 `reference/` 文件相同。

这里保存的是来源材料，未改写历史论证或绝对路径链接。早期总阶数审计含撤回声明，应使用后来的完整实时一阶推导；最终研究报告解释了最新版源码与历史节点布局的差异，以及历史错误已经修正的情况。

`scripts/verify_archive.py` 在普通克隆中直接核验这些快照，无需访问来源机器。原研究的 `source_audit.py` 保留原样，用于有原理论目录的机器重新审计来源；其原路径不可用时，以本目录的哈希快照为证。
