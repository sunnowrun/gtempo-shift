# 精度、实际 package 验证与性能比较

结论：Weyl 局部积分修正加精确系统对称半步，在固定有限正常自由浴上得到真正二阶时间离散，同时保留原物理 IF。K 与 IF 均有明确的重复主体张量。当前有限 GMPS 的新 K 构造偏慢，不能宣称耗时仍主要在 IF，更不能宣称已经实现 infinite MPS。

## 1. 模型、基准与实际步长

本节固定可复现模型，再区分时间离散、完整积分和张量近似。能量单位统一取浴能级及耦合给定的单位。

浴能级为 (0.43, −0.61)。单模耦合为 (0.7+0.13i, −0.22)。独立浴双模耦合矩阵为 ((0.7+0.13i, 0), (0, 0.41−0.09i))；共享浴双模为 ((0.7+0.13i, −0.22), (0.19i, 0.41−0.09i))。

杂质初始参数为 ε₁＝−0.31、ε₂＝−0.11、U＝1.1；淬火后为 ε₁＝0.27、ε₂＝0.17、U＝0.6。双模有 n₁n₂ 相互作用。观测量为 n₁，Green 函数使用明确顺序的 d 与 d†。β＝0.9，总实时间 t＝0.8。因子化实时浴态温度 βᵦ＝0.9，杂质初态占据基权重为单模 (0.65,0.35)、双模 (0.4,0.1,0.2,0.3)。

算符基准是完整杂质加有限浴 Hamiltonian 的精确矩阵指数。Python 与 Julia 采用同一物理模型、总时长、步长和插入位置，系统传播均用精确矩阵指数。

三条对照路线为：order1＝原 anti-Wick 重建加系统 Lie 分裂；bath_corrected＝上一种浴指数内部补偿加系统对称半步；weyl＝本次原物理浴加新局部积分。为公平比较 IF/K，在主体性能表中三者均使用相同的“每传播间隔一个源单元”布局。

原 package 实时 order=1 的额外全宽浴端点另行按其算符布局审计，保存在 python.json 的 package_endpoint；这项是 Python 重建的有限浴算符比较，不冒充运行了原 package 默认 K。其传播误差阶约为 1, 1, 1。三条主体路线的 Julia 验证是真正调用 package 的 IF 构造和收缩，使用本目录明确构造的 K。

实时 N＝32 的 TTI-k6 物理误差约 6.3×10⁻⁸，看似优于精确离散目标的约 1.14×10⁻⁶；但其相对于离散目标的算法误差约 1.07×10⁻⁶，说明两种误差偶然抵消。这不代表时间算法提高了阶数。

TTI-k6/k10 含其内部指数近似；增大 k 的变化独立于时间离散。Prony 展开也有拟合容差和项数上限；ExactTTI 名称不消除拟合或 GMPS 截断误差。最终使用 n≤32、有限两能级浴及 2 个拟合指数；实时普通 TTI 用 DMRGMult1（最多 6 次 sweep、容差 10⁻¹²）、D 上限 48，实时 ExactTTI 用 SVDCompression、D 上限 128，虚时为 SVDCompression、D 上限 256（初轮 3 个拟合指数的 N＝8 虚时数据另存），不能据此保证一般长记忆谱也同样准确。

现有 PartialIF/TTI 构造器的一次调用将行列限制在同一个 band。共享浴的跨模杂化系数不能用独立 band IF 相乘替代；本次共享浴的完整积分和重复张量是 Python 全模审计，Julia 的跨 band IF 构造仍需扩展。

mixed 当前没有专用 TTI-IF/ExactTTI 接口。实际运行的是九块系数 accessor 加 PartialIF；数学上的分段重复网络已独立验证，专门 TTI 软件仍未实现。没有对 mixed 虚实交叉块作 Toeplitz 投影。

## 7. 适用范围与尚未实现项

有限正常自由浴的二阶传播、原 IF、新 K 及有限重复张量表示已经闭合。多模相互作用与共享浴在 Python 完整代数/积分/传播中验证；实际 Julia 适配本次验证单杂质模、双浴能级。定理允许更一般偶 H_S，但不能把它说成本次 Julia 已运行过一般相互作用双模。

尚未实现 infinite MPS 固定点和长链环境算法、mixed 专门 TTI 接口、连续浴的一致误差界，以及高效的直接均匀 K 构造。有限链重复张量测试不会被称作 infinite MPS 实现。

所有数值结论均有原始数据可追溯，数值验证不能替代一般证明。Markdown 的定界、裸命令和 KaTeX 实际渲染由 check_markdown.py 显式检查。
