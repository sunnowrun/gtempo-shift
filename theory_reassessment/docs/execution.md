## 修复与负结果

早期导出失败是旧虚轴位移对 Nτ=1 访问第二列，故完整导出清单跳过该不受支持点；实轴 N=1 仍保留。一次在导出清单完成前启动的 Python 检查失败，随后按依赖顺序重跑。

GMPS 系数审计首次失败包含两项测试工具错误：空单项式的逆序对数对空集合求和未设初值；绝对系数抽取漏乘 GMPS 每站点 scaling 的全链乘积。修复后，同一离散目标的分子分母检查和非零 K 系数检查均通过。相对核抽取原本用真空系数归一化，不受这个绝对 scaling 漏项影响。该错误没有被解释为物理算法问题。

首尾半宽与正常链接仍是一阶；某些粗网格的 Q 占据因为抵消比 Weyl 更准确。旧 mixed 去掉附加符号虽然消除平台，有限步长误差仍比一致链接大。Weyl 接触门原型同网格更慢。上述负结果均在报告中保留。

## 可复现性边界

本次证明针对固定有限正常自由浴、有限偶杂质 Hamiltonian、精确系统半步与正确源单元积分。数值包含少模浴、相互作用杂质和局域共享浴审计，但没有建立连续谱统一误差常数、低温长时资源优势或无限固定点收敛。

本次没有改上游源码、创建生产 PR 或部署新 API。原报告的 Prony/延迟 MPO 数据继续作为先前证据引用，没有冒充本次新运行的完整 TTI 测试。最新实时 TTI 仍使用链接移动核，需要明确适配才能接入原 IF 的 Weyl K；mixed 跨实虚块也需要专门通道。
