## Mathematical and implementation findings

- Continuous Gaussian bath IF is exactly quadratic, with Δ = V g_B V†. Higher powers of coupling in an exact discrete-chain Schur kernel are due to different discrete objects/multiple exchanges within a cell, **not missing higher bath cumulants**.
- Relabeling Grassmann variables is harmless only if system action, measure, boundaries, initial state, and observables transform too. Shifting only IF changes discretization.
- Smooth exponentials remain exponentials after shifts; poles unchanged.
- Shifted same-branch sequence requires an independent nearest-neighbor contact E and delayed tail:
  - k₁ = E
  - k_d = f_(d−1) for d≥2.
- Stable representation uses contact plus delayed exponential states, no tiny-pole division. Kernel generator with r poles needs r+3 virtual states.
- Even Grassmann bilinears commute; local correction exponentials factor exactly, no BCH splitting error. MPS compression still introduces error.
- Finite contour boundaries break global Toeplitzness but permit identical bulk cells with special boundary tensors/corrections.
- Mixed contour includes correlated initial state and junction signs, so real-only shift cannot be transplanted independently.

### 1. Shift exactly changes reconstruction, not arbitrary interpolation

Let A = impurity Hamiltonian; B = H_bath + H_hyb; source generator L = H_bath + Σ(āF + F†a).

Original anti-normal coherent frame Q:

- Q[1]=I, Q[a]=d, Q[ā]=d†
- Q[aā]=I−n; Q[āa]=n−I
- Q[L²]=B²−G_Q, with G_Q=ΣFF†.
- For real h, R_Q = Q[e^(−ihL)] = e^(−ihB) + h² G_Q/2 + O(h³).

Original real full-width package:
P_raw = (R_Q U_A)^N R_Q, N system steps but N+1 full source cells.

**New result verified to whole-kernel machine precision**:
Current real `_vs_rt_acc` exactly equals bath source IF with N link cells:

- forward cell j source legs `(ā⁺_(j+1), a⁺_j)`
- backward cell j `(ā⁻_j, a⁻_(j+1))`.

This is a **normal coherent link symbol map N**, not same-node Q:

- N[aā]=−n; N[āa]=n.
- N[L²]=B²−G_N, G_N=ΣF†F.

Define normal system symbol f_A(h) by coherent kernel
k_A(ā,x) = exp(āx) f_A(h;ā,x).

Actual shifted single link:
T_h = N[f_A(h) e^(−ihL)].

**Do NOT replace this by e^(−ihA) R_N or R_N e^(−ihA)**. Symbol multiplication is not operator multiplication.

Leading defect:

T_h − e^(−ih(A+B)) = h² D_link + O(h³),

D_link = G_N/2 + (AB+BA)/2 − N[A_n L],

where A_n is normal symbol of A.
For one level A=ε_d n, the extra term is ε_d H_hyb/2, so
D_link = (G_N + ε_d H_hyb)/2.

Thus shift is still generally first order and exchanges one bath-occupation-weighted defect for another, besides eliminating extra source endpoint. No universal superiority.

### 4. Weyl/contact alternative

General reconstruction family Q_s[aā]=(1−s)I−n:

- Q_0=Q, Q_1=N, Q_1/2=Weyl.
- Q_s[L²] = B² − (1−s)G_Q − s G_N.
- Since G_Q+G_N=cI, c=Σ|V|², only s=1/2 universally turns quadratic defect into scalar.
- R_W(λ)=exp(λ²c/4) Q_1/2[e^(−λL)].
- symmetric system halves give local cubic/global quadratic error for finite normal bath, arbitrary finite even interacting impurity.
- λ=δτ, +iδt, −iδt; **λ²**, not absolute-square.
- Keep original unshifted physical source IF and fit tails conventionally.
- New K is needed, not just scalar times old K.
- In Gaussian pair coefficient basis `(k0,ku)` with u=aā:
  `[k0';ku'] = [[.5,−.5],[.5,1.5]] [k0;ku]`; odd coefficients unchanged.
- Contact map acts on coefficients, not multiplication by Grassmann polynomial.
- No extra bath endpoint.

Current Julia prototype applies five MPS sums per pair, potentially costly. Need measure warmed timings, avoid claiming best speed.

### 5. Simpler first-order alternative being tested

Keep Q/raw IF, give first and last real source cells half-width h/2 and interior h. Total source length T rather than T+h. K unchanged. This removes leading endpoint term but leaves source reconstruction first-order error. Bulk remains same TTI, only boundary cells differ. `contour_audit.py` latest now computes `half_endpoints` for real/mixed. Need inspect outcomes and perhaps native MPS confirmation.

### 6. Prony

Earlier original study already demonstrated contact+delayed exponential tails and finite-state stable representation. Retain conclusions but relate to newly derived N-vs-Q distinction.

Latest GTEMPO real `ExactTTIIF` and TTI paths **unconditionally use shifted generator**, with missing contact channel and other issues described original report. Therefore **do not claim native TTI interface automatically works with raw IF/Weyl** just because mathematics supports it. Existing lower-level `_ti_mpo_parts` supports raw Toeplitz, but integration requires convention option/adapter. Mixed native TTI still absent.
